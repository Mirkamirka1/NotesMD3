# Заметки

Простое офлайн-приложение для заметок в стиле Material 3 (Java, без аккаунтов и рекламы). Поиск, закрепление, цвета, свайп для удаления с отменой, динамические цвета Android 12+, тёмная тема.

Сборка: открыть в Android Studio и Build → Build APK(s), либо `gradle assembleDebug`. GitHub Actions собирает APK при каждом коммите.
